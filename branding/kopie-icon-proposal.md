# Kopie Icon Proposal (Tape Spool + Lines)

## Concept
- Black rounded-square app icon
- White tape spool on the left (recording/media)
- White transcript lines on the right (text/transcription)
- One segmented line to hint speaker turns / diarization

## Files
- `branding/kopie-icon-proposal.svg`: monochrome master concept (`1024x1024`)

## Design notes
- Chunky shapes so it remains readable at small macOS sizes (`16px`, `32px`)
- No thin strokes, gradients, or lettering
- Monochrome by default to match the current UI direction
- Optional future accent: tiny red `REC` dot (commented out in SVG)
